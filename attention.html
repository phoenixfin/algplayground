Attention — a soft lookup you can seeAttention — pencarian lunak yang bisa dilihat

Attention is how a model lets each word decide which other words to read. Mechanically it is a soft dictionary lookup: compare a query with every key, turn the match scores into weights with a softmax, and return the weighted blend of the values. Build that intuition in 2-D first, then see it work on a sentence.

Attention adalah cara model membiarkan tiap kata memutuskan kata lain mana yang dibaca. Secara mekanis ia adalah pencarian kamus yang lunak: bandingkan query dengan setiap key, ubah skor kecocokan menjadi bobot lewat softmax, lalu kembalikan campuran berbobot dari value. Bangun intuisinya dalam 2-D dulu, lalu lihat cara kerjanya pada sebuah kalimat.

Dot products grow with dimension — softmax saturatesDot product tumbuh bersama dimensi — softmax jenuh

Take random query and key vectors with unit-variance entries in d dimensions. Their dot product has standard deviation √d. In a real model d is 64 or more, so raw scores are huge, softmax collapses to one-hot, and gradients vanish. Dividing by √d keeps the scores at a sane scale. See it happen.

Ambil vektor query dan key acak dengan elemen bervarians satu di d dimensi. Dot product-nya punya simpangan baku √d. Pada model nyata d bernilai 64 atau lebih, jadi skor mentah sangat besar, softmax runtuh menjadi one-hot, dan gradient lenyap. Membagi dengan √d menjaga skor tetap pada skala wajar. Lihat sendiri.

One attention head, wired by handSatu attention head, dirangkai dengan tangan

In a real transformer the score between tokens i and j is xiᵀ WQ WKᵀ xj, with weights learned from data. Here we replace the learned matrix with a small table you can edit: how much does a token of type A care about a token of type B? plus a bias for nearby positions. It is a toy, but the maths after the scores — softmax, rows summing to 1, optional causal mask — is exactly the real thing.

Pada transformer nyata skor antar token i dan j adalah xiᵀ WQ WKᵀ xj, dengan bobot yang dipelajari dari data. Di sini matriks yang dipelajari itu diganti tabel kecil yang bisa kamu sunting: seberapa peduli token bertipe A pada token bertipe B? ditambah bias untuk posisi yang berdekatan. Ini mainan, tetapi matematika setelah skor — softmax, baris berjumlah 1, causal mask opsional — persis seperti aslinya.

  4. Naikkan τ (temperatur): setiap baris mendatar ke arah seragam. Turunkan: baris jadi runcing.

Attention is blind to order — so add position by handAttention buta urutan — jadi tambahkan posisi secara manual

Shuffle the tokens and plain attention gives the same set of outputs; it has no idea what comes first. The original Transformer adds to each token's vector a sinusoidal position code: pairs of sines and cosines at geometrically spaced wavelengths, like the hands of many clocks. Nearby positions get similar codes; far-apart ones don't.

Acak token-tokennya dan attention biasa tetap menghasilkan himpunan keluaran yang sama; ia tak tahu mana yang pertama. Transformer asli menambahkan ke vektor tiap token sebuah kode posisi sinusoidal: pasangan sinus dan kosinus pada panjang gelombang yang berjarak geometrik, seperti jarum banyak jam. Posisi berdekatan mendapat kode mirip; yang berjauhan tidak.

Try this
  1. Drag p: the peak follows, and the shape stays the same — the code encodes relative distance in a way a dot product can read.
  2. Lower the base to 101.5: wavelengths shrink, the similarity peak sharpens, and far positions start to look alike again (aliasing).
Coba ini
  1. Seret p: puncaknya mengikuti, dan bentuknya tetap sama — kode itu menyandikan jarak relatif dengan cara yang bisa dibaca dot product.
  2. Turunkan basis ke 101,5: panjang gelombang menyusut, puncak kemiripan menajam, dan posisi jauh mulai tampak mirip lagi (aliasing).

Where this connectsKe mana ini terhubung

← Convolution. A convolution reads a fixed local window with fixed weights; attention reads everything, with weights computed from the content.

← Konvolusi. Konvolusi membaca jendela lokal tetap dengan bobot tetap; attention membaca semuanya, dengan bobot yang dihitung dari isinya.

→ Language models. Stack attention + an MLP many times, predict the next token, and you have a GPT.

→ Model bahasa. Tumpuk attention + MLP berkali-kali, prediksi token berikutnya, dan jadilah GPT.
